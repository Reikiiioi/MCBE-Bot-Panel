MineDDoS v2 — это высокооптимизированная, модульная кроссплатформенная панель управления (C2) для проведения стресс-тестирования серверов Minecraft Bedrock Edition. В этом обновлении v2 вас ждет полностью переписанный бэкенд, лаконичный монохромный интерфейс "Dark Cloudflare" и поддержка всех современных версий игры.

> **Дисклеймер:** Данный инструмент создан исключительно в образовательных целях и для авторизованного тестирования на проникновение. Не используйте это ПО против серверов, владельцы которых не давали на это явного согласия.

---

## ✨ Основные возможности

- **🌐 Современный веб-интерфейс:** Красивый, отзывчивый монохромный дизайн с фоновой Canvas-анимацией и графиками в реальном времени.
- **🚀 Высокая производительность:** Использование Node.js Worker Threads (потоков) позволяет запускать сотни ботов на разных ядрах процессора без лагов веб-панели.
- **🌍 Полная локализация:** Встроенная поддержка английского и русского языков "из коробки".
- **🎮 Все версии Bedrock:** Поддержка 50+ версий протокола (от `0.14.3` до `1.26.30`).
- **🎨 Поддержка цветовых кодов Minecraft:** Логи сервера, MOTD и сообщения в чате парсятся и красятся с использованием стандартных кодов `§` прямо в браузере.
- **🤖 Одиночный бот (Ручное управление):** Подключите одного бота отдельно, чтобы читать чат сервера и отправлять команды прямо из панели.
- **🛡️ Защита от вылетов:** Улучшенная обработка пакетов RakNet предохраняет пул ботов от краша при работе с защищенными прокси-серверами (например, WaterdogPE).

## 🛠️ Установка и запуск

**Требования:**
У вас должен быть установлен [Node.js](https://nodejs.org/) (версии 18 или выше).

**1. Клонируйте репозиторий:**
```bash
git clone https://github.com/Reikiiioi/Minecraft-Bedrock-Edition-Bot-Panel.git
cd Minecraft-Bedrock-Edition-Bot-Panel
```

**2. Запустите проект:**
```bash
node start.js
```

**3. Интерактивная настройка:**
При первом запуске установщик автоматически:
- Спросит ваш язык (`en`/`ru`).
- Скачает все необходимые `npm` модули.
- Попросит придумать пароль панели (или нажмите Enter, чтобы войти без пароля).

**4. Откройте панель:**
Перейдите в браузере по адресу:
```
http://127.0.0.1:3000
```

## ⚙️ Оптимизация и требования

Запуск множества клиентов Bedrock требует значительного объема оперативной памяти.

- **Слабое железо (1 vCPU, 1GB RAM):**
  - Используйте не более 1-2 потоков.
  - Задержка спавна: минимум 2-3 секунды.
  - Рекомендуемый лимит ботов: 20-30.
- **Мощное железо:**
  - Можно ставить 4-8+ потоков.
  - Задержка: 0.5 - 1 секунда.
  - Лимит ботов: 100+.
