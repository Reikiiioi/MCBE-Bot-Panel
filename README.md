# BotMCBE (Python Edition)

Высокопроизводительный асинхронный контроллер ботов и веб-панель управления для Minecraft: Bedrock Edition (MCPE) на базе `r-python-bedrock-protocol`.

---

## ⚡ Особенности

- **Чистый Python**: Нет задержек и зависимостей Node.js.
- **Веб-панель в реальном времени**: Обертка на `aiohttp` и WebSocket.
- **Оркестрация ботов**: Запуск роя из любого количества ботов с рандомными именами и эмуляцией разных устройств (Windows, Android, iOS, Nintendo).
- **Служебный чат**: Отправка сообщений в игровой мир.
- **Живая статистика**: Подсчет онлайн-ботов, отключений, сообщений и ошибок.

---

## 🚀 Быстрый запуск

1. Установите зависимости библиотеки (если ещё не установлены):
   ```bash
   pip install r-python-bedrock-protocol aiohttp
   ```

2. Запустите веб-панель:
   ```bash
   python start.py
   ```

3. Откройте панель в браузере: `http://localhost:3000`
